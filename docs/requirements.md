# 英语文章练习系统需求文档

## 1. 项目目标

构建一个英语文章练习系统。系统预置中英文文章，用户按文章英文内容逐个输入单词；当当前单词超过 3 秒未输入完成时，系统展示提示信息。练习完成后，系统统计完全正确数量、单词意思正确但不适用数量、错误数量，并展示逐词明细。

第一版只实现练习闭环，不实现登录、权限、个人历史列表和文章后台管理。

## 2. 文章等级

文章按英文内容长度分为四级：

| 等级 | 名称 | 规则 |
| --- | --- | --- |
| 1 | 短句练习 | 不超过 10 个英文单词 |
| 2 | 长句练习 | 可以超过 10 个英文单词 |
| 3 | 短文练习 | 100 个英文单词内 |
| 4 | 长文练习 | 可以超过 100 个英文单词 |

## 3. 文章内容

每篇文章包含：

- 中文原文
- 英文原文
- 等级
- 单词序列

每个单词包含：

- 英文单词
- 词性
- 中文翻译
- 语法链接

第一版文章内容通过数据库初始化脚本预置。

## 4. 练习流程

1. 用户进入首页后选择文章等级和文章。
2. 系统展示中文原文、英文原文和当前练习进度。
3. 用户按顺序逐个输入英文单词。
4. 当前单词超过 3 秒仍未提交时，系统展示提示：单词、词性、翻译、语法链接。
5. 用户提交当前单词后进入下一个单词。
6. 所有单词提交完成后，用户结束练习。
7. 系统返回练习统计和逐词明细。

## 5. 判定规则

- 完全正确：用户输入与目标单词规范化后完全一致。
- 单词意思正确但不适用：用户输入与目标单词不一致，但 AI 判断其语义接近或中文意思正确，不过不适合当前英文原文上下文。
- 错误：不符合以上两类。

非精确匹配答案在结束练习时调用 OpenAI Responses API 进行语义判定，使用结构化 JSON 输出。若 OpenAI 配置缺失或调用失败，结束练习接口返回明确错误，不生成兜底统计。

## 6. 接口范围

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/articles` | 查询文章列表，支持按等级筛选 |
| GET | `/api/articles/:id` | 查询文章详情和单词序列 |
| POST | `/api/practice-sessions` | 开始练习 |
| POST | `/api/practice-sessions/:id/answers` | 提交单词输入 |
| POST | `/api/practice-sessions/:id/finish` | 结束练习并返回统计 |

## 7. 非功能要求

- 后端监听所有 IP：`0.0.0.0`。
- 时区固定：`Asia/Shanghai`。
- 日期格式：`yyyy-mm-dd`。
- 时间格式：`hh24:mm:ss`。
- 前端请求后端统一使用同源相对路径 `/api`。
- 日志统一写入 `logs/log_yyyy-mm-dd.log`，每行一条 JSON。
- 数据库使用 MySQL 8.0。
- 部署脚本支持 `start`、`stop`、`restart`。
